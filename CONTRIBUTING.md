# Como contribuir

O EcoMapa é desenvolvido de forma colaborativa. Para manter o repositório
organizado e facilitar a revisão das contribuições:

- faça alterações pontuais e relacionadas a um único objetivo;
- evite misturar mudanças independentes no mesmo commit ou Pull Request;
- mantenha os arquivos claros, organizados e consistentes com o restante do
  projeto;
- use nomes claros para branches, commits e arquivos;
- revise as alterações antes de enviá-las;
- documente mudanças que afetem o conteúdo, a organização ou o uso do projeto;
- prefira Pull Requests pequenos e objetivos, sempre que possível.

## Fluxo recomendado

1. Atualize sua cópia do repositório.
2. Crie uma branch para a tarefa.
3. Faça as alterações necessárias.
4. Revise o que foi modificado.
5. Registre a alteração em um commit claro e objetivo.
6. Abra um Pull Request para revisão.

Exemplo de nome de branch:

```text
interface/filtros-laterais
```

Exemplo de mensagem de commit:

```text
Move filtros para a barra lateral
```

## Antes de enviar uma alteração

Verifique se:

- a alteração atende ao objetivo proposto;
- os textos estão em Português do Brasil;
- não foram incluídos arquivos ou mudanças sem relação com a tarefa;
- a documentação relacionada foi atualizada, quando necessário;
- informações pessoais ou sensíveis não foram adicionadas ao repositório.

## Registro de participação

Ao começar a colaborar, adicione seu nome ao arquivo
[`CONTRIBUTORS.md`](CONTRIBUTORS.md).

As áreas de atuação podem mudar durante o projeto. O registro deve refletir a
participação de cada integrante de forma simples e objetiva.
