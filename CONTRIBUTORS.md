# Colaboradores

Este arquivo registra os integrantes do projeto e ajuda a tornar visível a
participação de cada pessoa.

Preencha apenas informações adequadas para publicação em um repositório.

| Nome | GitHub | Área ou interesse principal | Atuação no projeto |
|---|---|---|---|
| A preencher | @usuario | Ex.: interface, API, banco de dados | Ex.: desenvolvimento da tela inicial |
| A preencher | @usuario | Ex.: documentação | Ex.: revisão do README |
| A preencher | @usuario | Ex.: testes | Ex.: testes de usabilidade |

## Orientações

- Use o nome pelo qual deseja ser identificado no projeto.
- Informe o usuário do GitHub apenas se desejar.
- Descreva áreas de interesse de forma breve.
- Atualize a coluna de atuação conforme o projeto evoluir.
- Não registre telefone, endereço, documentos ou outros dados pessoais.
